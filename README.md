# Елена — сайт-портфолио финансового аналитика

Одностраничный сайт-презентация для поиска клиентов на удаленную и гибридную работу.
Профиль: финансовый анализ, управленческий учет, контроль расчетов, налоговый учет, автоматизация в Excel и Google Sheets.

## Зачем этот репозиторий

Это не «резюме в интернете», а инструмент продажи экспертизы. Задача сайта — за несколько секунд дать потенциальному клиенту ответ на три вопроса:

1. Кто этот человек и с какими задачами работает?
2. Какую конкретную проблему он решает и что я получу в результате?
3. Как выстроена работа в удаленном формате и безопасно ли это?

## Структура страницы

| Блок | Что показывает |
|---|---|
| Hero | Позиционирование: одна фраза о результате, а не список навыков |
| Чем я могу быть полезна | Пять услуг, каждая — в формате «что делаю → что это дает клиенту» |
| Как я работаю удаленно | Снимает страх «как я буду тебя контролировать» |
| С чем ко мне обычно приходят | Типичные боли клиента — чтобы он узнал свою ситуацию |
| Форматы сотрудничества | Проект / абонентское сопровождение / консультации |
| Контакты | LinkedIn, email, профиль на профессиональной платформе |

## Технические характеристики

- **Один файл**: `index.html` — весь CSS и JS внутри, внешних зависимостей нет.
- **Работает офлайн**: достаточно открыть файл в браузере.
- **Адаптивность**: одна колонка на мобильных, две — от 720px.
- **Доступность**: семантические теги, контрастные цвета, фокус-стили для клавиатуры.
- **SEO-минимум**: `lang="ru"`, один `h1`, корректная иерархия `h2 → h3`, `meta description`.
